Platypicker

A searchable popover for native selects. Open any picker below and try it.

This browser doesn't support appearance: base-select, so the pickers fall back to plain selects.

Single select

A plain select wrapped in a platy-picker. Pick with the mouse or arrow keys, or type the first letters of an option.

<platy-picker><select class="form-select"></platy-picker>

Search and subtext

Filters as you type. Matches are highlighted in both the label and the subtext.

search search-placeholder="Search cities…" data-subtext

Multiple

Click several options. The select shows everything chosen.

multiple size="1"

Select all and none

Select all acts on the options matching the current filter. Single selects only get Select none, and required selects hide it too.

controls select-all-label="Take them all" select-none-label="Clear"

Groups, dividers, disabled

Plain options, an <hr> divider, a disabled option with subtext, a tooltip from title, a disabled group, and an option after a group (which gets its own divider).

<optgroup> <hr> disabled title

Batches

Long lists are rendered a batch at a time, and the next batch follows as you scroll down. Searching still covers every option. A batch size of 0 renders everything.

batch-size="20" batch-size="0"

Placeholders

Skeleton rows after the last rendered option, for as long as more are still to come. With a local list they only flash by, because the next batch is rendered before you reach it.

placeholders="4" batch-size="4"

Sizes and validation

Bootstrap sizes and validation states carry over, including the feedback text.

form-select-sm form-select-lg is-valid is-invalid

Live changes

setValue() updates the picker without firing change, by design. Adding or removing options, or toggling attributes, updates an open or closed picker.

Large list benchmark

Builds a car list, then times open, search and pick. Each action is timed up to the second frame after it, and the median of 3 runs is shown. Build is the time to the first rows, and Rendered is the time until the whole list is in the page. Runs stack so you can compare before and after a change.
